# 🛡️ CyberVault: Project Null Byte

> A web-based Capture The Flag (CTF) platform designed for cybersecurity training, penetration testing education, and hands-on security investigations.

## 🚀 Project Overview

CyberVault: Project Null Byte is a multi-domain cybersecurity CTF platform developed as part of the IE3132 Penetration Testing module.

Participants take the role of junior penetration testers investigating a simulated cyber attack through progressive challenges covering multiple cybersecurity domains.

## 🎯 Features

✅ User Authentication & Access Control

✅ Challenge Dashboard

✅ Flag Submission & Validation

✅ Real-Time Score Tracking

✅ Multi-Domain Cybersecurity Challenges

✅ Web-Based Learning Environment

✅ Security Controls & Challenge Isolation
